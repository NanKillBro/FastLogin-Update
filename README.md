#  FastLogin Updated
## 📌 Overview

FastLogin Updated is a maintained and modernized fork of the original FastLogin plugin, designed to provide seamless automatic authentication for premium players on offline-mode servers.

This version focuses on compatibility with newer versions of Spigot/Paper, along with bug fixes and internal improvements to ensure better stability and performance.

## ⚙️ Features
### ✔ Automatic login for premium (online-mode) players
### ✔ Works with offline-mode servers
### ✔ Compatible with modern Spigot and Paper versions
### ✔ Improved stability and performance
### ✔ Bug fixes from the original version
### ✔ Maintained and updated for current environments
## 📦 Compatibility
### 🔹 Spigot / Paper (latest versions)
### 🔹 Compatible with Geyser/Floodgate setups (if applicable)
## 🔧 Dependencies
### 📌 ProtocolLib

Required for packet interception and proper functionality.

👉 https://www.spigotmc.org/resources/protocollib.1997/

## 🔐 Supported Authentication Plugins

FastLogin requires an authentication plugin to manage offline-mode players.

### ⭐ Recommended
🔸 AuthMeReloaded

👉 https://modrinth.com/plugin/authmereloaded

### ⚠️ Other plugins

Other authentication plugins may work, but compatibility is not guaranteed.

## 🚀 Installation
### 1️⃣ Download the plugin .jar file
### 2️⃣ Place it in your /plugins folder
### 3️⃣ Configure your server:
Open the server.properties file
Set:
online-mode=false
### 4️⃣ Restart your server
